# Big Data & NoSQL Collection

This repository contains a collection of assignments submitted for the "Big Data" course. It covers various database technologies and data processing tools including SQLAlchemy, MongoDB, Pandas, and TF-IDF text similarity.

## Contents

### 1. SQLAlchemy User/Media Management (`sqlalchemy_user_media.py`)
A complete ORM-based implementation using SQLAlchemy to manage:
- Users with encrypted passwords
- Media items and view histories
- Custom repository and service layer abstraction
- Features: user registration, media tracking, validation, and history analytics

---

### 2. Nintendo Game Rental with MongoDB (`mongodb_nintendo_game_rental.py`)
Implements a full-stack MongoDB system for user registration and game rentals. Includes:
- TF-IDF-based recommendation system
- Genre-based weighted game suggestion
- MongoDB aggregates for genre distribution and user analytics

---

### 3. Basic Data Queries
A set of initial exercises working with basic data extraction and transformation logic.
